# AroLink (SwasthSetu) - Last-Mile Healthcare for Rural India

Smart India Hackathon 2026 | Problem Statement 26133 (Government of Maharashtra)

## Overview
AroLink empowers ASHA workers with an offline-first, multilingual, voice-guided digital health app acting as the human bridge to ABDM (Ayushman Bharat Digital Mission).

### System Architecture
- **mobile/**: React Native / Expo ASHA mobile app (Offline-first, tri-lingual Marathi/Hindi/English, CDSS triage, local queue sync)
- **backend/**: FastAPI REST service connecting to ABDM sandbox, triage ML, visit logging, and referrals
- **dashboard/**: PHC facility web dashboard for live queue, stock tracking, and doctor teleconsult console
